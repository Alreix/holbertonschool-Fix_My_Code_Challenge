# Fix My Code Challenge

## Description

This repository contains solutions for the **Fix My Code Challenge** project.

The goal of this project is to work on an existing code base, understand the bugs, and fix them without rewriting everything from scratch.

Each task contains a broken implementation that must be corrected while keeping the original logic as much as possible.

## Project Requirements

* All files are compiled or interpreted on Ubuntu 20.04 LTS.
* All files must end with a new line.
* The code should follow the project requirements.
* The goal is to fix the existing code, not to completely rewrite it.

## Tasks

### 0. FizzBuzz

Language: Python

Fixes a FizzBuzz implementation where numbers divisible by both 3 and 5 were printing `Fizz` instead of `FizzBuzz`.

### 1. Print Square

Language: JavaScript

Fixes a square printing program where the size argument was parsed using base 16 instead of base 10.

### 2. Sort

Language: Ruby

Fixes a sorting program where integers were inserted at the wrong index, causing an incorrect order.

### 3. User Password

Language: Python

Fixes a User class where the hashed password was stored in the wrong attribute and compared using the wrong case.

### 4. Double Linked List

Language: C

Fixes a doubly linked list delete function where node links were incorrectly updated and memory was accessed after being freed.
